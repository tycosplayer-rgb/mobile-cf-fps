# 移动端 FPS 骨架（穿越火线手游风格操控）

基于 **Vite + Three.js** 的横屏触控 FPS 可玩骨架。单机、轻量，适合在手机浏览器里试手感。

灵感来自穿越火线手游的常见布局：左侧虚拟摇杆移动，右侧拖动瞄准，右下角开火 / 换弹 / 跳跃 / 开镜。

## 功能一览

- 左摇杆：移动 / 平移
- 右侧拖动：视角瞄准
- 开火、换弹、跳跃、开镜（ADS）
- HUD：准星、弹药、生命、命中提示
- 小型竞技场 + 可击倒并重生的移动靶子
- 桌面调试：WASD + 鼠标（点击画布锁定指针）、左键开火、R 换弹、空格跳跃、Shift 开镜

## 本地运行

需要 Node.js 18+。

```bash
npm install
npm run dev
```

浏览器打开终端里提示的本地地址（默认 `http://localhost:5173`）。

生产构建预览：

```bash
npm run build
npm run preview
```

## 手机同网测试

1. 电脑运行 `npm run dev -- --host`（或本仓库已在 `vite.config.js` 里开启 `host: true`）。
2. 确保手机与电脑在同一 Wi‑Fi。
3. 用手机浏览器访问终端显示的局域网地址，例如 `http://192.168.x.x:5173`。
4. 将手机**横屏**，点「开始游戏」。

若局域网被隔离（访客 Wi‑Fi 等），可用隧道临时穿透，例如：

```bash
npx cloudflared tunnel --url http://localhost:5173
# 或
npx localtunnel --port 5173
```

把生成的 https 链接发到手机浏览器即可。

## 操作说明

| 操作 | 触控 | 键鼠 |
|------|------|------|
| 移动 | 左侧摇杆 | WASD / 方向键 |
| 瞄准 | 右侧拖动 | 鼠标（指针锁定） |
| 开火 | 「开火」键 | 鼠标左键 |
| 换弹 | 「换」 | R |
| 跳跃 | 「跳」 | 空格 |
| 开镜 | 「镜」 | Shift / 鼠标右键 |

## 技术栈

- Vite
- Three.js（WebGL）
- 原生触控事件（无额外 UI 框架）

## 已知限制（骨架阶段）

- 非联机；靶子为简单巡逻假人，无 AI 还击
- 无音效 / 复杂枪械模型 / 后坐力曲线细化
- 碰撞为简化 AABB；未做完整物理
- 部分浏览器需用户手势后才能锁定横屏 / 全屏
