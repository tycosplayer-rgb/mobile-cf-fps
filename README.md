# 移动端 FPS（音效 · 枪感 · 对战）

基于 **Vite + Three.js** 的横屏触控 FPS。布局灵感来自穿越火线手游：左侧摇杆移动，右侧拖动瞄准，右下角开火 / 换弹 / 跳跃 / 开镜。

在线试玩：[https://tycosplayer-rgb.github.io/mobile-cf-fps/](https://tycosplayer-rgb.github.io/mobile-cf-fps/)

## 功能一览

- **音效**：开火、空仓、换弹、命中、受伤、击杀、脚步；Web Audio 程序生成；开始手势后解锁；HUD 静音按钮
- **枪感**：后坐力（镜头 + 持枪）、散射/Bloom、开镜更准、枪口闪光、屏幕震动、命中准星与伤害数字、爆头强化反馈
- **对战（PvP）**：房间码创建/加入，PeerJS 公网信令 + WebRTC 数据通道实时同步位置/开火/伤害/重生
- **单机练习**：巡逻靶子；击倒后保持死亡，**全部消灭后**再统一重生（波次）
- HUD：准星（随散射张开）、弹药、生命、击杀播报、静音、灵敏度设置
- 桌面调试：WASD + 鼠标（点击画布锁定指针）、左键开火、R 换弹、空格跳跃、Shift / 右键开镜

## 如何联机对战

1. 双方用手机或电脑打开同一页面（GitHub Pages 或本地预览均可）。
2. 填写昵称。一方点 **「创建对战房间」**，记下 4 位房间码。
3. 另一方输入房间码点 **「加入」**。
4. 大厅里看到双方后，**房主**点 **「开始对战」**。
5. 同一地图互相射击；被击倒后等待本回合结束（全员淘汰或仅剩一人）再共同重生。

也可点 **「单机练习（靶子）」** 不联机练枪。

**重生规则**：练习靶子与 PvP 均不采用「死后立即个人重生」。练习模式在清场（全部靶子死亡）后统一复活；PvP 在回合结束（无人或仅剩一人存活）后短延迟共同重生。

### 联机原理与限制

| 项目 | 说明 |
|------|------|
| 架构 | 房主星型拓扑：客户端 ↔ 房主 WebRTC DataChannel；房主转发状态 |
| 信令 | [PeerJS](https://peerjs.com/) 免费公共云（`0.peerjs.com`），**无需 API Key / 自建服务器** |
| 房间人数 | 建议 ≤ 6；超出可能拒绝加入 |
| NAT / 防火墙 | 部分严格网络（公司网、对称 NAT）可能连不上，可换手机热点或家庭宽带重试 |
| 公平性 | 轻量同步，命中由射击方检测后通知对方扣血（适合休闲，非反作弊服务器） |
| 依赖 | `three`、`peerjs`（对战首次创建/加入时动态加载） |

公共信令偶发不稳定时，刷新页面并重新建房通常可恢复。

## 本地运行

需要 Node.js 18+。

```bash
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 `http://localhost:5173/mobile-cf-fps/`）。

生产构建：

```bash
npm run build
npm run preview
```

`vite.config.js` 中 `base` 为 `/mobile-cf-fps/`，与 GitHub Pages 项目页路径一致。推送到 `main` 后，Actions 会自动构建并部署 Pages。

## 手机同网测试

1. 电脑运行 `npm run dev`（已开启 `host: true`）。
2. 手机与电脑同一 Wi‑Fi，访问终端里的局域网地址。
3. 横屏后选择练习或联机。

若局域网隔离，可用临时隧道：

```bash
npx cloudflared tunnel --url http://localhost:5173
```

## 操作说明

| 操作 | 触控 | 键鼠 |
|------|------|------|
| 移动 | 左侧摇杆 | WASD / 方向键 |
| 瞄准 | 右侧拖动 | 鼠标（指针锁定） |
| 开火 | 「开火」键 | 鼠标左键 |
| 换弹 | 「换」 | R |
| 跳跃 | 「跳」 | 空格 |
| 开镜 | 「镜」 | Shift / 鼠标右键 |
| 静音 | HUD 🔊 | 点击静音按钮 |
| 灵敏度 | 大厅滑条 / 局内 ⚙ | 同上（1–10，默认 5；写入 localStorage） |

### 灵敏度设置

- 大厅主菜单可调 **灵敏度**（触控瞄准与鼠标共用）。
- 对局中点 HUD **⚙** 打开设置，可随时调整后点「继续游戏」。
- 刻度 **1–10**（默认 **5** 约为原先手感）；内部映射倍率约 **0.3×–2.5×**，开镜仍相对腰射约 **0.55×**。
- 偏好保存在浏览器 `localStorage`（键 `mcfps-look-sens`），下次打开自动加载。

## 技术栈

- Vite
- Three.js（WebGL）
- PeerJS（WebRTC 联机）
- Web Audio API（程序化音效）
- 原生触控事件（无额外 UI 框架）

## 已知限制

- 碰撞为简化 AABB；未做完整物理
- 枪械为简易 viewmodel，非精细模型
- PeerJS 公共云无 SLA；严肃联机需自建 PeerServer / 中继
- 部分浏览器需用户手势后才能解锁音频 / 全屏 / 横屏锁定
